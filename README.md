# FPS Display — Minecraft Java 1.21.11

Fabric client-side mod.

Features:
- Press **N** to open a small rectangular settings panel in the top-right.
- Click **FPS DISPLAY** to enable/disable it.
- Enabled state makes the button green.
- A boxed `FPS: number` HUD appears in-game.
- While the N menu is open, click-drag the FPS box to reposition it.

Target: Minecraft Java Edition 1.21.11, Fabric, Java 21.
